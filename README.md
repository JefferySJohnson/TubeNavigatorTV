# TubeNavigatorTV

A Tube status board for the Apple TV — the status-only companion to TubeNavigator (iPhone/iPad). Currently **v1.18 (build 19)** — code complete 23 Nov 2026; build/verification pending (a computer-control approval timed out before the TV build ran — retry on Jeffery's say-so). v1.17 was built and verified on the simulator the same day; v1.16 is the version on the Samsung 55.

- **Status**: London weather at the top (WeatherKit, fixed to Paddington — the hotel; live since 22 Nov 2026), with the condition's own icon and a forecast strip underneath (toggle it in Settings), then one button per line — name, status colour and status name — all thirteen on one screen, two columns, as a clean list with no button fills. Each button is capped at 720pt and left-aligned in its column (v1.6), so the white focus pill is narrower than the full column. Green for Good Service, orange otherwise; the focused button's status word goes black so it stays readable on the white focus pill. Tap a button for the full disruption message on its own screen, with a "‹ Back to all lines" button to return. At the top of the tab (v1.13): the tab's title on the left, and the Refresh button with the time of the last successful check ("Updated HH:mm") at the upper right. There is no footer any more — the version lives only in Settings. **v1.16: the forecast strip is tappable** — press it to cycle 7 days → next 12 hours → today (condition, high/low, rain chance, sunrise/sunset), with a hint under the row; the view you pick sticks across launches.
- **Planned**: dated disruptions — strikes and engineering works — for the next 7 days or the Dec 15–24 trip, grouped by day, with London-time ranges and the full reason. Same TfL data as the iPhone app's Planned tab. Switch ranges with the two buttons under the header row ("Next 7 days" / "Trip · Dec 15–24") — in v1.0 this was a segmented Picker the remote could not reach, so v1.1 replaced it with buttons. v1.7 made the tab one step smaller in type throughout, with tighter padding and no grey fill behind the range buttons. **v1.16: "Next 7 days" is the default** (was the Trip range); the choice isn't saved, so every launch opens on the next seven days.
- **Live** (new in v1.9): six central London traffic cameras from TfL's own JamCam network — Westminster Bridge, Parliament Square, Piccadilly Circus, Trafalgar Square, Oxford Circus, Tower Bridge. Each row shows the camera's still as a thumbnail, the camera name, and "Tap to watch". Tap a camera to play the latest clip (about 11 seconds, refreshed every few minutes — a moving snapshot, not a continuous stream) in the native video player; it loops until you leave, and a "‹ Back to live views" button takes you back to the list. There are no cameras inside Tube stations — TfL doesn't publish those — so these are street cameras near the places that matter. One note: a camera's thumbnail can occasionally be TfL's grey "in use keeping London moving" placeholder when the camera is in use by their control room; the clip itself still plays.
- **Map** (new in v1.10): the Tube diagram with the thirteen line buttons beside it. Focus a button and that line lights up on the map, with its live status in a panel underneath. The diagram is the September 2026 TfL map, cropped to the diagram; each line's path was extracted once from the map PDF by colour.
- **Boards** (new in v1.11): departure boards, like the ones in the stations. Pick a station (seven since v1.15: Paddington, Canary Wharf, King's Cross St. Pancras, Liverpool Street, London Bridge, Victoria, Waterloo), and the board shows the next five trains on each platform — destination (with "via" on the Elizabeth line), minutes away, the arrival clock time in London time, and where the train is now. It refreshes itself every 30 seconds. **v1.14:** a train at a minute or less shows "arriving" instead of "due"; the board is two screens now (picker, then a full-screen board per station with the lines across the top); the arrival sound — a soft bong when a train on the open board first drops to a minute or less, switchable in Settings. **v1.15:** the "Back to stations" button is gone (the remote's Back returns to the picker) and Canary Wharf joined (Elizabeth, Jubilee, DLR). **v1.16:** moving focus across the line buttons switches the board without pressing Select; the station name + line buttons stay pinned at the top while only the trains scroll; platform A always sits on top at Paddington. **v1.18:** the Paddington Elizabeth line board shows only the underground platforms A and B — the feed also returns the mainline station's platforms 11 and 12 (late-night trains ending at Paddington mainline), and those rows are dropped. Only Tube, Elizabeth line and DLR trains appear — mainline trains (GWR, Heathrow Express) are not in this TfL feed.
- **Settings** (new as a tab in v1.11; the screen itself is from v1.8): the last tab, gear icon. Left: the app icon, the build version, and the data sources. Right: a theme picker (four dark schemes — Midnight, Tube Navy, Oxblood, Forest; dark only, because the white focus pill can't be recoloured), a "Show forecast" toggle (v1.16 rename — was "Show 7-day forecast"), and a **Sound** section (v1.14: "Arrival sound" on/off, default on, plus the sound picker — Bong, Chime, Bell). There is no "‹ Back" button any more — Settings is a tab, so there is nothing to go back from.

No journey planning, no saved places or pubs — the telly is for glancing at, not planning on.

Data: Transport for London Unified API (`https://api.tfl.gov.uk`), free, no key required. Weather via WeatherKit — needs the explicit App ID `com.rolltide.TubeNavigatorTV` registered with the WeatherKit capability in the developer portal; that step is done (the weather strip went live during 22 Nov 2026).

Built with SwiftUI, tvOS 17, Xcode on the MacBook Pro. Bundle `com.rolltide.TubeNavigatorTV`. App icon is the TfL roundel with "JEFF" as the station name, plus a Top Shelf image.
